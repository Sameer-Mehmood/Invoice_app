Connect Google

Templates live as real Google Docs, so invoices get Google's own layout, tables, and PDF rendering instead of anything we simulate by hand. This is a one-time setup.
  1. Go to Google Cloud Console and create a project (or reuse one).
  2. Under APIs & Services → Library, enable the Google Docs API and Google Drive API.
  3. Under APIs & Services → OAuth consent screen, set it up for "External" (Testing is fine for personal use — add yourself as a test user).
  4. Under APIs & Services → Credentials, create an OAuth client ID of type "Web application".
  5. Add this page's URL to Authorized JavaScript origins (e.g. https://yourname.github.io — a real hosted URL, not a local file).
  6. Paste the Client ID below and sign in.
Saved only in this browser. Never sent anywhere except directly to Google.
If Drive calls ever fail with a permission error even while signed in, the fallback is broadening the requested scope from drive.file to drive in the source — a note for whoever maintains this if that comes up.

Templates

Each template is a real Google Doc. Design it in Docs — add your logo as an image, format freely, and build a table for line items — then sync so this app can find your placeholders.
Sign in with Google to create or sync templates.
Line items use a numbered convention: {{description_1}}, {{qty_1}}, {{price_1}} for row 1, {{description_2}} etc. for row 2, and so on. Build as many rows as you'll ever plausibly need in the Doc's table — this app fills however many you use on a given invoice and blanks the rest. It can't add rows beyond what already exists in the template.
